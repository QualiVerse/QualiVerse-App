# QualiVerse Desktop

QualiVerse brings academic accreditation and quality assurance work into one place. Teams can organize accreditation frameworks, assign standards and indicators, collect supporting evidence, and follow the progress of each review cycle. The desktop app gives staff and reviewers access to these workflows from Windows and macOS.

## Download and install

| Platform | Download | Installation |
| --- | --- | --- |
| Windows | [Download the installer](https://github.com/QualiVerse/QualiVerse-App/releases/latest/download/QualiVerse.Te.V2.exe) | Run the installer, then open **QualiVerse.Te.V2** from the Start menu or desktop shortcut. |
| macOS | [Download the ZIP archive](https://github.com/QualiVerse/QualiVerse-App/releases/latest/download/QualiVerse.Te.V2-macOS.zip) | Extract the archive, move **QualiVerse.Te.V2.app** to **Applications**, and open it there. |

You will need a QualiVerse account to sign in. If your organization manages access, contact its administrator for an account or the appropriate permissions.

## What you can do

- **Manage accreditation work:** Browse frameworks, standards, criteria, and indicators for the relevant academic year and department.
- **Coordinate assignments:** Assign work to team members with deadlines and track its status.
- **Collect evidence:** Upload files to the relevant indicator so reviewers can find the supporting material in context.
- **Review submissions:** Approve evidence or request changes with a clear rejection reason.
- **Stay informed:** Receive notifications about assignments, uploads, and review outcomes, with links to the related work.
- **Work across the system:** Use dashboards and workspaces to monitor activity and progress.

Available features depend on your account and permissions.

## Updates

The installed app checks for new releases and can update itself. You can also download the latest package or browse previous versions on the [releases page](https://github.com/QualiVerse/QualiVerse-App/releases).
